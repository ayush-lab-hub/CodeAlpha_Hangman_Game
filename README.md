# CodeAlpha Task 1 - Hangman Game 🎮

## 📖 Project Overview
This project is part of the **CodeAlpha Internship Program**.  
It is a simple text-based Hangman game built using Python where the player tries to guess a hidden word one letter at a time.

---

## 🎯 Game Rules
- A random word is selected from a predefined list of words
- Player has **6 incorrect attempts**
- Each correct guess reveals the letters in the word
- Game ends when:
  - Player guesses the full word correctly ✅
  - OR attempts run out ❌

---

## ⚙️ Features
- Random word selection using Python
- Letter-by-letter guessing system
- Limited attempts (6 lives)
- Win / Lose conditions
- Simple console-based interface

---

## 🧠 Concepts Used
- Python `random` module
- While loops
- If-else conditions
- Strings and lists
- Basic game logic
